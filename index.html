GenLayer Asimov

A public register that flags an agent whose own output contradicts the model it claims.

You cannot prove which model is behind an agent from a page its operator controls. You can catch a contradiction. Register a claim, that an agent runs a model, with a fingerprint challenge, a prompt whose answer reveals the model. Anyone can then submit the subject's public response to that challenge, and a round of GenLayer validators reads it and decides whether the response reveals a different model. If the agent's own answer names another model, the claim is flagged. A claim left standing is not a certificate; it is simply uncontradicted.
